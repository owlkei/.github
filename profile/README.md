---

Most of a web app's time goes into gluing pieces together: a component library, a backend, a
database, auth, real-time updates and the tooling to see what is going on. Owlkei builds those
pieces to fit from the start, so you can write the part that is yours. Everything is meant to be
written by hand and to be easy for AI assistants to use correctly.

## Products

| | |
|---|---|
| **Owlkei UI** | Accessible, themeable components, blocks and templates. One design system, in plain HTML or through framework packages such as React. Nine design styles, light and dark, AA contrast everywhere. |
| **Owlkei Go** | Build Go backends the way you think. Name a method, get a route: REST APIs, server-rendered pages that use Owlkei UI, and WebSocket in one framework, with modules and dependency injection that wire your app for you. Built-in storage and cache, one binary. |
| **[Owlkei SDK](https://github.com/owlkei/sdk)** | Client SDK for Owlkei Go apps, in TypeScript and Go. WebSocket first, HTTP next. |
| **Owlkei Devtools** | *Coming later.* Point it at your app's URL to see its modules, routes, traces and data, and to send test requests. |

## Status

Owlkei is in active development and not released yet. The SDK is public today; the other
products open up as they reach their first releases. Follow [owlkei.com](https://owlkei.com) for
news.
